現在式 Presente

規則動詞去掉字尾 -ar / -er / -ir 後，依詞尾加上對應變化：

人稱-ar-er-ir
yo-o-o-o
tú-as-es-es
él/ella/usted-a-e-e
nosotros-amos-emos-imos
ellos/ellas/ustedes-an-en-en

範例：hablar → hablo, hablas, habla, hablamos, hablan／comer → como, comes, come, comemos, comen／vivir → vivo, vives, vive, vivimos, viven

⚠ 詞根母音變化動詞（stem-changing）在現在式除 nosotros 外都會變化：pedir (e→i) → pido／dormir (o→ue) → duermo／jugar (u→ue) → juego／seguir (e→i，且 gu→g) → sigo。

簡單過去式 Pretérito indefinido

描述過去某個時間點「已完成」的單一動作。

人稱-ar-er / -ir
yo-é-í
tú-aste-iste
él/ella/usted-ó-ió
nosotros-amos-imos
ellos/ellas/ustedes-aron-ieron

範例：hablar → hablé, hablaste, habló, hablamos, hablaron／comer → comí, comiste, comió, comimos, comieron

⚠ 拼寫子音變化（保留原音，只發生在 yo 人稱）：-car→qu（buscar→busqué）、-gar→gu（llegar→llegué, pagar→pagué, jugar→jugué）。

⚠ -ir 詞根母音變化動詞，只有第三人稱（單/複數）才變化：pedir→pidió/pidieron、dormir→durmió/durmieron、seguir→siguió/siguieron。

⚠ 不規則詞根動詞（整個詞根換掉，字尾改用 -e/-iste/-o/-imos/-ieron，且 yo/él 不加重音）：tener→tuve, estar→estuve, poder→pude, poner→puse, saber→supe, hacer→hice（但 él→hizo）, querer→quise, venir→vine, decir→dije（第三人稱複數是 dijeron，不是 dijieron，因為詞根以 j 結尾）。

⚠ ser／ir 的簡單過去式完全相同：fui, fuiste, fue, fuimos, fueron，需靠上下文判斷語意。dar 的簡單過去式沒有重音符號：di, diste, dio, dimos, dieron。

未完成過去式 Pretérito imperfecto

描述過去的習慣、背景描述，或動作進行中但不強調何時結束。

人稱-ar-er / -ir
yo-aba-ía
tú-abas-ías
él/ella/usted-aba-ía
nosotros-ábamos-íamos
ellos/ellas/ustedes-aban-ían

範例：hablar → hablaba, hablabas, hablaba, hablábamos, hablaban／vivir → vivía, vivías, vivía, vivíamos, vivían

⚠ 西語只有 3 個未完成過去式不規則動詞：ser → era, eras, era, éramos, eran；ir → iba, ibas, iba, íbamos, iban；ver → veía, veías, veía, veíamos, veían。本 app 涵蓋的動詞中僅 ser／ir 屬此類，其餘一律規則變化。

未來式 Futuro simple

直接在「完整原形動詞」後面加字尾，三組動詞（-ar/-er/-ir）字尾完全相同：

人稱字尾
yo-é
tú-ás
él/ella/usted-á
nosotros-emos
ellos/ellas/ustedes-án

範例：hablar → hablaré, hablarás, hablará, hablaremos, hablarán

⚠ 未來式的「不規則」只發生在詞幹（原形被截短或改變），字尾仍然規則：tener→tendr-、poder→podr-、querer→querr-、saber→sabr-、poner→pondr-、salir→saldr-、venir→vendr-、hacer→har-、decir→dir-。例：tener → tendré, tendrás, tendrá, tendremos, tendrán。

條件式 Condicional simple

字尾規則與未完成過去式的 -er/-ir 組完全相同，同樣加在「完整原形動詞」後面：

人稱字尾
yo-ía
tú-ías
él/ella/usted-ía
nosotros-íamos
ellos/ellas/ustedes-ían

範例：hablar → hablaría, hablarías, hablaría, hablaríamos, hablarían

⚠ 條件式的不規則詞幹與未來式完全一樣（同一組特殊詞幹，字尾規則）：tendría, podría, querría, sabría, pondría, saldría, vendría, haría, diría。

常見易混淆重點

  • ser vs ir 的簡單過去式完全相同（fui/fuiste/fue/fuimos/fueron），要靠上下文判斷是「是」還是「去」。
  • decir 的簡單過去式第三人稱複數是 dijeron，不是 dijieron（詞根以 j 結尾時，字尾用 -eron 而非 -ieron）。
  • jugar 的簡單過去式 yo 是 jugué（g→gu 保留硬音），不是 jugé。
  • seguir 的現在式 yo 是 sigo（gu→g，因為 o 前面 gu 會發硬音，需去掉 u）。
  • saber 的現在式 yo 是 sé（帶重音符號，與反身代名詞 se 拼字不同）。
  • dar 的簡單過去式沒有重音符號（di/diste/dio/dimos/dieron），容易誤加。
  • 詞根母音變化動詞（pedir/dormir/seguir/jugar）：現在式除 nosotros 外都變化；簡單過去式只有 -ir 動詞的第三人稱（單/複數）才變化，-ar 動詞（如 jugar）簡單過去式不變。
